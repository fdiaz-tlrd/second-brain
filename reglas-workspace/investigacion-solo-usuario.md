| Campo | Valor |
|-------|-------|
| Fecha | 2026-09-23 |
| Ubicación | `second-brain/reglas-workspace/` (fijo) |

## Regla

- `second-brain/` es sitio compartido Cursor ↔ usuario para documentar.
- **`second-brain/investigacion/`** es **solo del usuario**.
- El agente puede **leer** si el usuario lo señala (p. ej. un error en un `.md`).
- El agente **no** escribe el resultado de estudios ahí: crea/actualiza otra carpeta bajo `second-brain/` (ej. `alb/`).

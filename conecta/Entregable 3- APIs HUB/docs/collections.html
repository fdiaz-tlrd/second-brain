Collections API — Panama Interoperability HUB (1.0.0-draft)

Download OpenAPI specification:

Panama Interoperability HUB — Developer Support: hub-support@[operator-domain]

Collection requests (Request-to-Pay / QR, pain.013/pain.014 semantics): the creditor initiates a collection request that the debtor's participant must accept or reject. For P2M collections the creditor may be given as creditorId (subfield 26.04 of the interoperable QR). The debtor's response (pain.014 semantics) is submitted on the response endpoint; an accepted request generates a payment order linked through requestId. Errors use application/problem+json with a reasonCode from the HUB error code catalogue.

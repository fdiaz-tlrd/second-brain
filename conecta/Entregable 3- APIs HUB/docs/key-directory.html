Key Directory API — Panama Interoperability HUB (1.0.0-draft)

Download OpenAPI specification:

Panama Interoperability HUB — Developer Support: hub-support@[operator-domain]

Resolution and lifecycle of person keys (aliases) in the HUB directory: online resolution, registration/update/deregistration with prxy.001/002 semantics, portability between participants (48-hour window: if the current owner does not oppose, the portability is confirmed automatically) and account-name verification. Key resolution is never cached. Errors use application/problem+json with a reasonCode from the HUB error code catalogue.

Resolution

Online key resolution (transactional path)

Resolve a person key

Lifecycle

Key registration, update and deregistration (prxy.001/002)

Register a key (prxy.001 REGISTER)

Registers a key on behalf of the authenticated participant. If the key is already registered at another participant the HUB answers 409; the correct path is portability. nationalIdHash is optional in phase 1 and becomes mandatory once alias–national-ID validation is activated.

Portability

Key portability between participants

Request key portability (prxy.001 PORT)

Initiated by the receiving participant. The key moves to PORTING; the current owner receives KEY_PORT_REQUESTED and confirms or opposes within the portability window (48 h). Silence is interpreted as consent.

Reconciliation API — Panama Interoperability HUB (1.0.0-draft)

Download OpenAPI specification:

Panama Interoperability HUB — Developer Support: hub-support@[operator-domain]

Reconciliation file exchange over API with mTLS (SFTP remains as a bounded compatibility channel): download of the participant's filtered reconciliation file for a cycle (daily calendar-day cycle, 7×365) and acknowledgement with discrepancy reporting. File availability and window opening/closing are announced through the notification channel (Events API). Errors use application/problem+json with a reasonCode from the HUB error code catalogue.

Files

Cycle file download and acknowledgement

Download the filtered reconciliation file of the cycle

Returns the file filtered to the authenticated participant's scope (master file = net positions; format based on recon.001).

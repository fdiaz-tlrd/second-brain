Panama Interoperability HUB — Developer Support: hub-support@hub.example.pa License: Proprietary

Reconciliation cycle exchange (daily calendar-day cycle, 7×365). The cycle is governed by the HUB calendar: the HUB determines the end of the operating day, closes the cycle, runs the batch reconciliation engine and emits the RECONCILIATION_FILE_AVAILABLE event; participants do not push cycle records. The file is retrieved as a physical file through a short-lived secure URL (no file payload inside an API response), respecting the exchange security rules; SFTP remains as a bounded compatibility channel. The participant then acknowledges the cycle and reports discrepancies through this API. Errors use application/problem+json with a reasonCode from the HUB error code catalogue.

Files

Cycle file download and acknowledgement

Obtain the secure download reference of the cycle file

Returns the download descriptor of the file filtered to the authenticated participant's scope (master file = net positions; format based on recon.001). The response carries a short-lived secure URL to retrieve the physical file — the file content never travels inside the API payload.

x-jws-signature
required
string non-empty

Detached JWS signature of the exact request body, using compact serialization with an unencoded payload (b64=false) as defined by RFC 7515 and RFC 7797. The protected header must contain alg, kid, b64:false and crit:["b64"]. Algorithms are restricted to PS256 or ES256; none and symmetric algorithms are forbidden. kid identifies an active signing key registered for the authenticated participant. Key publication and rotation use the participant metadata registered during onboarding.
